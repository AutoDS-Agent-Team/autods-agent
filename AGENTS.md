# AutoDS-Agent contributor rules

These rules apply to every future task in this repository.

- Maintain a modular architecture with clear boundaries between API, services, data access, and schemas.
- Keep API routes thin; routes validate input, delegate work, and format responses.
- Put business logic inside service modules.
- Use typed Pydantic request and response models at application boundaries.
- Use environment variables for configuration and secrets. Never commit real credentials.
- Never execute arbitrary code generated by an LLM.
- Every LLM-controlled operation must follow: **LLM -> structured JSON plan -> Pydantic validation -> registered trusted Python functions**.
- In future ML modules, fit preprocessing only on training data to prevent leakage.
- Add meaningful tests for important behaviour and regressions.
- Do not add dependencies unless the current implementation needs them.
- Keep Docker-based development and deployment working.
- Do not push to GitHub unless the user explicitly requests it.
